Actual Budget is a free, open-source personal finance application built on the envelope budgeting method. Unlike most finance apps, Actual is **local-first**: your data lives in a SQLite database on your own device, not on someone else's server. Synchronization across devices is optional and handled by a lightweight sync server you control. There are no subscription fees, no ads, and no third-party access to your financial data.

## What is Actual Budget?

Actual Budget gives you a structured way to manage money using **envelope budgeting** — you assign every dollar you have to a spending category before you spend it. Each month you fill your "envelopes," track spending against them, and roll any leftover money forward. This approach keeps you aware of exactly where your money is going and encourages intentional spending decisions.

## How it compares to hosted services

Most personal finance apps — YNAB, Mint, Monarch, and others — store your data on their servers, require an active subscription to function, and can disappear or change pricing at any time.

| | Actual Budget | Typical hosted service |
|---|---|---|
| **Cost** | Free (MIT license) | $5–$15/month |
| **Data location** | Your device | Provider's servers |
| **Privacy** | No third-party access | Provider can read your data |
| **Offline access** | Full functionality | Depends on the service |
| **Continuity** | You own the files | Tied to the service's existence |
| **Bank sync** | Optional, via open providers | Usually bundled, opaque |

## Architecture overview

Actual is a TypeScript/JavaScript monorepo composed of several packages, each with a distinct role.

### loot-core

The heart of Actual. `loot-core` (`packages/loot-core/`) contains all business logic: budget calculations, transaction processing, the query layer (AQL), rules engine, sync protocol, importers, encryption, and the SQLite database layer. It is platform-agnostic and ships separate entry points for browser and Node.js environments. All other packages depend on it.

### desktop-client

The React-based web UI (`packages/desktop-client/`, aliased `@actual-app/web`). It runs in any modern browser as well as inside the Electron wrapper. Built with Vite, it uses the React Compiler for automatic memoization. This is the interface you interact with day-to-day — budget views, account registers, reports, rules, and settings.

### sync-server

The optional synchronization server (`packages/sync-server/`, aliased `@actual-app/sync-server`). It is an Express-based Node.js server that persists encrypted budget change messages and makes them available to other clients. It does not interpret your budget data — it stores opaque binary payloads. You can deploy it via Docker, Fly.io, PikaPods, or the npm CLI tool.

### desktop-electron

The Electron wrapper (`packages/desktop-electron/`) that packages `loot-core` and `desktop-client` into installable desktop applications for Windows, macOS, and Linux. When using the desktop app, no sync server is needed — everything runs locally.

### @actual-app/api

The Node.js API package (`packages/api/`). It exposes programmatic access to your budget for scripting, automation, and integrations. You can use it to bulk-import transactions, export data, run reports, and more. Install it with `npm install @actual-app/api`.

<Note>
The sync protocol uses a CRDT (Conflict-free Replicated Data Type) implementation (`packages/crdt/`) to merge changes from multiple devices without conflicts. This is what makes offline edits safe to synchronize later.
</Note>
